# Photo Instructions

Place your profile photo in this directory with the name `profile.jpg`.

Recommended photo specifications:
- File name: profile.jpg
- Size: At least 240x240 pixels (will be displayed at 120x120)
- Format: JPG/JPEG
- Type: Professional headshot
- Aspect ratio: 1:1 (square)

Tips for a good profile photo:
1. Use a professional headshot with good lighting
2. Ensure your face is clearly visible
3. Use a neutral background
4. Dress professionally
5. Crop to a square format before saving

Until you add your photo, the site will show a placeholder SVG icon.
